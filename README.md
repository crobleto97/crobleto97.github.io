# Christian Robleto Romero, portfolio

Static site on GitHub Pages, no build step.

- Project status: set `data-status="planned|progress|done"` on the project `<li class="station">` in `index.html` and update its pill text.
- After changing `styles.css` or `main.js`, bump the `?v=` number where they are linked (index.html and projects/*.html) so browsers fetch the new version.
