Operations analytics platform

An end-to-end analytics project on public e-commerce and logistics data: from raw CSV files to a star schema in PostgreSQL and a Power BI report built for operations decisions.

Status In progressOrder Project 1 of 3Type Personal project

The problem

Operations teams usually have the data to answer questions about late deliveries, supplier reliability or margin by region, but it sits in flat exports that nobody has joined or modelled. Reports get rebuilt by hand every month and the numbers rarely match between them.

How it works

  1. Ingest. Python loads the raw files, fixes types and logs what it rejected.
  2. Validate. Data-quality checks on keys, nulls, duplicates and value ranges before anything reaches the database.
  3. Model. PostgreSQL star schema: fact tables for orders and deliveries, dimensions for customer, product, supplier, geography and date.
  4. Query. SQL views with CTEs and window functions for the business KPIs.
  5. Report. Power BI on top of the model, with Power Query and DAX measures for revenue, margin, on-time delivery and retention.

Stack

Python, pandas, PostgreSQL, SQL, Power BI, Power Query, DAX.

What I'll measure

  • Revenue, margin and order volume by region and category
  • On-time delivery rate and average delay by supplier
  • Customer segmentation and retention by cohort
  • Rows rejected by each data-quality check
