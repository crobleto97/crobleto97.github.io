Document agent with evaluation

A retrieval agent that answers questions from a set of technical or procedural documents, returns structured answers with sources, and hands off to a person when its confidence is low.

Status PlannedOrder Project 2 of 3Type Personal project

The problem

Calling an LLM API is easy. Knowing whether a new version of an assistant got better or worse is the hard part. This project is built around a fixed test set, so every change to prompts, chunking or retrieval can be measured.

How it works

  1. Classify. Detect what the question is asking and whether it needs the documents at all.
  2. Retrieve. Search chunks stored in PostgreSQL with pgvector and score their relevance.
  3. Answer. Generate a structured answer validated with Pydantic, citing the chunks it used.
  4. Check. Verify the answer is grounded in the cited sources.
  5. Escalate. Send low-confidence answers to human review instead of returning them.

Stack

Python, LangGraph, Pydantic, PostgreSQL with pgvector, embeddings, LLM APIs.

What I'll measure

  • Answer correctness on a 50-question test set
  • Retrieval quality and groundedness
  • Latency and cost per question
  • Failure and escalation rate
