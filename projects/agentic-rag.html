Document agent with evaluationAgente documental con evaluación

A retrieval agent that answers questions from a set of technical or procedural documents, returns structured answers with sources, and hands off to a person when its confidence is low.Un agente de recuperación que responde preguntas sobre un conjunto de documentos técnicos o de procedimientos, devuelve respuestas estructuradas con fuentes y pasa el caso a una persona cuando su confianza es baja.

The problemEl problema

Calling an LLM API is easy. Knowing whether a new version of an assistant got better or worse is the hard part. This project is built around a fixed test set, so every change to prompts, chunking or retrieval can be measured.Llamar a la API de un LLM es fácil. Lo difícil es saber si una nueva versión de un asistente ha mejorado o empeorado. Este proyecto gira en torno a un conjunto de pruebas fijo, así que cada cambio en los prompts, el troceado o la recuperación se puede medir.

How it worksCómo funciona

  1. Classify. Detect what the question is asking and whether it needs the documents at all.Clasificar. Detectar qué pide la pregunta y si necesita los documentos.
  2. Retrieve. Search chunks stored in PostgreSQL with pgvector and score their relevance.Recuperar. Buscar fragmentos guardados en PostgreSQL con pgvector y puntuar su relevancia.
  3. Answer. Generate a structured answer validated with Pydantic, citing the chunks it used.Responder. Generar una respuesta estructurada, validada con Pydantic, que cita los fragmentos usados.
  4. Check. Verify the answer is grounded in the cited sources.Comprobar. Verificar que la respuesta se apoya en las fuentes citadas.
  5. Escalate. Send low-confidence answers to human review instead of returning them.Escalar. Enviar las respuestas con poca confianza a revisión humana en lugar de devolverlas.

Stack

Python, LangGraph, Pydantic, PostgreSQL with pgvector, embeddings, LLM APIs.Python, LangGraph, Pydantic, PostgreSQL con pgvector, embeddings, APIs de LLM.

What I'll measureQué voy a medir

  • Answer correctness on a 50-question test setExactitud de las respuestas en un conjunto de 50 preguntas
  • Retrieval quality and groundednessCalidad de la recuperación y grado de fundamentación
  • Latency and cost per questionLatencia y coste por pregunta
  • Failure and escalation rateTasa de fallos y de escalado
